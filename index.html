Big picture

 ┌──────────────────────── main thread (app.js) ────────────────────────┐
 │  state · rendering · events · i18n · tour · help · terminal API      │
 │   ├─ viewer.js     before/after layer: zoom, pan, split handle       │
 │   ├─ props.js      image properties, EXIF read / copy                │
 │   └─ zip.js        ZIP archive (STORE, UTF-8 names)                  │
 └───────────────┬──────────────────────────────────────────────────────┘
                 │ postMessage(file, options)  ◀── result Blob back
 ┌───────────────▼──────── Web Worker (worker.js) ──────────────────────┐
 │ createImageBitmap → OffscreenCanvas → encode                         │
 │ (search.js: binary search over quality for target size)              │
 │ → optional Exif copy with Orientation = 1 → Blob                     │
 └──────────────────────────────────────────────────────────────────────┘
